## Reporting a Vulnerability

Please report security vulnerabilities by opening an issue at https://github.com/Liaeor/publish-guide/issues.
Do **not** report security vulnerabilities via public GitHub issues if they contain sensitive information.

Instead, email the maintainer directly (contact information available in the repository profile).

We will acknowledge receipt within 48 hours and provide a timeline for a fix.
